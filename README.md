# Color Detection Tool

A Python-based color detection tool that detects colors in an image based on mouse clicks. The tool identifies the color name, RGB values, and displays it on the image.

---

## Features

- Detects colors in any image by clicking on it.
- Displays the closest color name from a dataset.
- Simple and easy to use.

---

## Requirements

### **1. Software Dependencies**
- Python 3.8 or higher
- Libraries:
  - OpenCV (`opencv-python`)
  - Pandas
  - NumPy

### **2. Dataset**
The project uses a `colors.csv` file as a dataset containing predefined color names, RGB values, and HEX codes.
